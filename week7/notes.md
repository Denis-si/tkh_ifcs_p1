# Week 7 — Reconnaissance, Network Enumeration & Vulnerability Triage

**TKH Innovation Fellowship 2026 | Phase 1 | Cybersecurity**

## What I Learned

This week focused on executing full-scope security assessments by combining passive Open Source Intelligence (OSINT), active network interrogation, and context-driven vulnerability triage. The core technical skills involved conducting subdomain and tech-stack mapping via automated reconnaissance tools, executing aggressive network-wide service version scans with `nmap`, and auditing web server configurations using `Nikto`. These offensive activities directly informed a defensive posture by applying the security principle of Risk-Based Vulnerability Management—proving that filtering vulnerability noise based on actual business risk ($\text{Risk} = \text{Likelihood} \times \text{Impact}$) is critical to effectively protecting an organization's perimeter.

## Artifacts

* **ThreatProfile_CloudNano.md** An OSINT threat profile capturing passive reconnaissance findings and digital footprint mappings. I generated this by leveraging tools like Sublist3r, BuiltWith, and HaveIBeenPwned to identify exposed subdomains, tech-stack footprints, and leaked credentials without initiating direct interaction with the target network.
* **nmap_scan_results.txt** A comprehensive network enumeration map detailing active hosts and their associated service environments. I produced this artifact by running ping sweeps across target subnets followed by aggressive service version detection (`nmap -sV`) to expose legacy or vulnerable daemon versions.
* **remediation_plan.md** A strategic, risk-adjusted remediation roadmap that distills raw technical findings into a prioritized list of the top five critical fixes. I authored this plan by triaging threats based on exposure and business context, deliberately prioritizing internet-facing flaws like unauthenticated cloud storage and injection vectors over generic high-CVSS scores on isolated systems.
* **Perimeter_Assessment.md** A professional, executive-ready assessment report compiling the unified findings of "Operation Shadow Map." I engineered this final document to provide CISOs and engineering teams with a clear view of discovered assets, validated web server misconfigurations (such as missing security headers), and strategic risk justifications.

## Challenges & How I Solved Them

A primary challenge this week was handling the immense volume of vulnerability data and false positives generated by active scanning tools, which can easily overwhelm an engineering team's bandwidth. For example, the web security audit flagged dozens of missing headers and minor compliance warnings alongside severe infrastructure exposures. I solved this bottleneck by implementing a strict risk-scoring triage framework, manually validating the exploitability of each finding against its specific network exposure, and filtering out the environmental "noise." This allowed me to deprioritize high-CVSS items on air-gapped segments and instead focus immediate remediation efforts on exposed, high-impact external assets.

## Reflection

This week's milestones demonstrate that effective reconnaissance and scanning are not just about finding flaws, but about translating raw technical findings into actionable business context. Thinking like an attacker is necessary to map the true attack surface, but thinking like a lead engineer is what ensures an organization's limited defensive resources are deployed efficiently. In future assessments, I plan to integrate automated asset discovery scripts earlier in the reconnaissance loop to maintain an ongoing, real-time perimeter inventory.
